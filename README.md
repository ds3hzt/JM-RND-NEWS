# JM R&D 최신 동향 — 4차: 자동 게시 워크플로 포함

## 사용 화면
- **오늘의 동향**: 한국 날짜의 뉴스 5건. 당일 미등록 시 정직하게 미등록 표시.
- **과거 동향**: 왼쪽 날짜 / 오른쪽 5개 제목의 세로 목록. 제목을 누르면 상세 해설. 검색과 분류 지원.
- **news.json**: 게시된 뉴스만 저장. 시연용 가상 자료는 `sample-news.json`으로 분리했습니다.

## GitHub Pages 배포 및 자동화
1. 이 ZIP을 압축 해제한 후 **`jm-rnd-news` 폴더 안의 파일과 `.github` 폴더**를 GitHub 저장소 루트에 업로드합니다. `.github`는 숨김 폴더이므로 반드시 포함합니다.
2. GitHub 저장소 **Settings → Pages → Deploy from a branch → main / (root)** 선택해 게시합니다. 처음 배포까지 시간이 걸릴 수 있습니다.
3. GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 `OPENAI_API_KEY`를 추가합니다. API 사용료는 별도로 발생할 수 있습니다.
4. 저장소 **Actions → Daily JM R&D News → Run workflow**를 눌러 수동 시험합니다. 성공 시 `news.json`에 날짜별 5건이 누적되고 홈페이지에 반영됩니다.
5. GitHub Actions는 매일 **한국시간 오전 7시**(UTC 22:00)에 실행을 시도합니다. 실제 실행/배포 시각은 지연될 수 있어 정확히 7시 게시를 보장하지 않습니다.

## 자동 뉴스 품질 및 주의사항
- 최근 7일 Google News RSS 제목·링크·발행일을 수집한 뒤 OpenAI API로 한국어 요약/배경/현장 적용을 작성합니다.
- 기사 전문을 읽는 방식이 **아니므로** 기사 제목만으로 확인되지 않는 수치·계약 사실 등은 작성하지 않도록 제한했습니다. 원문 링크를 함께 제공합니다.
- 후보 5건 미만, 결과 5건 미만, 출처 불일치 또는 국내/해외 균형 미달 시 **게시하지 않고 오류 처리**합니다. 이전 기록은 보존합니다.
- GitHub 저장소를 공개하면 뉴스 페이지도 누구나 접근할 수 있습니다. API 키는 저장소 파일에 넣지 마세요.
- **카카오톡 채널 메시지 자동 발송은 미구현**입니다. 카카오 공식 발송 권한·채널 설정 및 서비스 비용을 확인하고 별도 연동해야 합니다.
- 이 ZIP 자체는 인터넷에 게시된 사이트가 아닙니다. 저장소 업로드 및 설정은 사용자의 GitHub 계정에서 해야 합니다.
